# 作业 3: 其他 Attention 机制

在本节中，我们将详细介绍除了 Multi-Head Self-Attention 之外的其他常见 Attention 机制，包括它们的优缺点和使用场景。

---

## **1. Global Attention (Soft Attention)**
- **描述**: 
  - 对所有输入序列的每个位置计算注意力权重。
  - 输出是所有输入的加权和。
- **优点**:
  - 能捕获全局信息。
  - 适合处理长序列。
- **缺点**:
  - 计算复杂度高，尤其是序列较长时。
  - 无法区分局部和全局信息。
- **使用场景**:
  - 机器翻译（如早期的 Seq2Seq 模型）。
  - 文本摘要生成。

---

## **2. Local Attention**
- **描述**: 
  - 只关注输入序列的局部区域（窗口）。
  - 在窗口内计算注意力权重。
- **优点**:
  - 计算效率高，适合长序列。
  - 更适合捕获局部模式。
- **缺点**:
  - 无法捕获全局依赖。
  - 窗口大小的选择可能影响性能。
- **使用场景**:
  - 图像处理（如卷积神经网络中的注意力）。
  - 语音识别。

---

## **3. Additive Attention (Bahdanau Attention)**
- **描述**: 
  - 使用一个可学习的函数（如前馈神经网络）来计算 Query 和 Key 的相似性。
  - 通过加法操作计算注意力分数。
- **优点**:
  - 更灵活，适合不同类型的输入。
  - 在小型数据集上表现较好。
- **缺点**:
  - 计算效率较低。
- **使用场景**:
  - 机器翻译（如 Bahdanau Attention）。
  - 小型 NLP 任务。

---

## **4. Scaled Dot-Product Attention**
- **描述**: 
  - 使用 Query 和 Key 的点积计算注意力分数，并通过缩放因子 \( \sqrt{d_k} \) 进行归一化。
- **优点**:
  - 计算简单高效。
  - 在大规模数据上表现良好。
- **缺点**:
  - 对小型数据集可能不够灵活。
- **使用场景**:
  - Transformer 模型中的核心注意力机制。

---

## **5. Sparse Attention**
- **描述**: 
  - 只计算部分 Query 和 Key 的注意力分数（稀疏矩阵）。
- **优点**:
  - 计算效率高，适合超长序列。
  - 节省内存。
- **缺点**:
  - 可能丢失部分信息。
- **使用场景**:
  - 长序列建模（如 Longformer、BigBird 等）。

---

## **6. Cross-Attention**
- **描述**: 
  - Query 来自一个序列，Key 和 Value 来自另一个序列。
- **优点**:
  - 能捕获两个序列之间的交互信息。
- **缺点**:
  - 计算复杂度较高。
- **使用场景**:
  - 多模态任务（如图像-文本匹配）。
  - Transformer 解码器中的 Encoder-Decoder Attention。

---

## **7. Hard Attention**
- **描述**: 
  - 选择性地关注输入的一部分（非连续），而不是对所有输入加权。
- **优点**:
  - 更加高效，适合资源受限的场景。
- **缺点**:
  - 不可微分，难以训练。
- **使用场景**:
  - 图像目标检测。
  - 强化学习任务。

---

## **8. Self-Attention Variants**
- **描述**: 
  - 包括多种自注意力的变体，如因果注意力（Causal Attention）。
- **优点**:
  - 针对特定任务优化。
- **缺点**:
  - 可能需要额外的设计和调试。
- **使用场景**:
  - 因果注意力：语言模型（如 GPT 系列）。

---

## **总结**
| Attention 类型         | 优点                          | 缺点                          | 使用场景                     |
|------------------------|-------------------------------|-------------------------------|-----------------------------|
| Global Attention       | 捕获全局信息                 | 计算复杂度高                 | 机器翻译、文本摘要          |
| Local Attention        | 高效，捕获局部模式           | 无法捕获全局依赖             | 图像处理、语音识别          |
| Additive Attention     | 灵活，适合小数据集           | 计算效率低                   | 小型 NLP 任务              |
| Scaled Dot-Product     | 高效，适合大规模数据         | 小数据集上可能不够灵活       | Transformer 核心机制       |
| Sparse Attention       | 高效，适合超长序列           | 丢失部分信息                 | 长序列建模                 |
| Cross-Attention        | 捕获序列间交互信息           | 计算复杂度高                 | 多模态任务、Transformer 解码器 |
| Hard Attention         | 高效，适合资源受限场景       | 难以训练                     | 图像目标检测、强化学习      |
